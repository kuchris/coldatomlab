# Cold Atom Lab

An interactive virtual laboratory for exploring Bose–Einstein condensate (BEC) expansion and matter-wave interference.

## Status

Project planning. The simulation and interface are not implemented yet.

## Proposed first release

- Prepare a trapped condensate and release it to observe expansion.
- Prepare two coherent clouds, control their relative phase, and observe interference.
- Inspect density, phase, and quantitative measurements during evolution.
- Save experiment parameters and results for reproducible comparisons.

The proposed model is an effective two-dimensional Gross–Pitaevskii equation for a dilute, weakly interacting condensate. It starts with a prepared condensate; it does not model the full laser-cooling and condensation process.

See [PLAN.md](PLAN.md) for implementation milestones and validation requirements.
